# SpendWise Interactive Dashboard

SpendWise is a simple budgeting and expense tracking web application.

The project was developed using HTML, CSS, and JavaScript. The main goal of this version is to transform the original static dashboard into an interactive application.

## Features

- Monthly budget tracking
- Dynamic total spending calculation
- Remaining budget calculation
- Add new expenses
- Delete individual expenses
- Clear all expenses
- Expense categories
- Dynamic category percentages
- Budget status messages
- Responsive dashboard design
- Interactive DOM updates
- JavaScript event handling

## Technologies Used

- HTML5
- CSS3
- JavaScript
