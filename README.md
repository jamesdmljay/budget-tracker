# SpendWise – Personal Budget Tracker

## 1. Project Description

SpendWise is a responsive personal budget tracking web application designed to help users manage their finances effectively. It enables users to set monthly budgets, record expenses, monitor spending, and track their remaining balances.

The application provides a simple and user-friendly dashboard that promotes better financial planning and responsible spending habits.

## 2. Technologies Used

The project was developed using the following technologies:

- **HTML5** – Provides the structure of the application.
- **CSS3** – Handles styling, layout, and responsive design.
- **JavaScript** – Implements interactivity, calculations, and dynamic functionality.
- **Git & GitHub** – Used for version control and project hosting.
- **Netlify** – Used for website deployment and continuous deployment.

## 5. Deployment Process Summary

The application was deployed using GitHub and Netlify through the following steps:

1. Reviewed and organized the project files to ensure deployment readiness.
2. Created a public GitHub repository named `budget-tracker`.
3. Uploaded the complete SpendWise project files to GitHub.
4. Connected the GitHub repository to Netlify.
5. Configured Netlify to deploy the application from the repository.
6. Successfully published the website using Netlify.
7. Changed the default Netlify subdomain to `spendwise-dmljay.netlify.app`.
8. Tested the live website to confirm that its components and functionality were working correctly.
9. Updated the application, pushed the changes to GitHub, and verified that Netlify automatically deployed the latest version.

## 6. Challenges Encountered During Deployment

During the development and deployment process, I encountered several challenges:

- **Git Merge Conflicts:** Encountered conflicts while synchronizing local project files with the GitHub repository. These were resolved by reviewing and correcting the conflicting files.
- **CSS Layout Adjustments:** Experienced challenges with certain visual elements, including logo sizing and application layout, which required additional styling adjustments.
- **GitHub Synchronization:** Had to ensure that local changes were properly committed and pushed to the remote repository.
- **Deployment Verification:** Needed to confirm that updates pushed to GitHub were automatically reflected on the live Netlify website.

These challenges were addressed through troubleshooting, testing, and making the necessary corrections.
